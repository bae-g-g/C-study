# 02. 입출력 및 연산자

## 이미지 매칭 메모

`IO`는 입출력, `R`은 관계 연산, `O`는 논리 연산, `CA`는 컴퓨터 구조와 임시변수, `Tc`는 형변환, `FPB`는 실수의 이진 표현 자료에 우선 연결해서 사용합니다. `A.png`처럼 주제와 맞지 않는 캡처는 대표 자료에서 제외했습니다.

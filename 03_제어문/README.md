# 03. 제어문

프로그램의 실행 흐름을 반복과 분기로 제어하는 단원입니다.

조건문을 이해한 뒤 반복문과 분기문을 함께 보며, 어떤 상황에서 흐름이 바뀌는지 코드 실행 순서를 따라가는 것이 핵심입니다.

## 권장 학습 순서

| 순서 | 문서 | 내용 |
| --- | --- | --- |
| 1 | [반복문 강의](./01_반복문_강의.md) | `for`, `while`, `do while`의 실행 흐름 |
| 2 | [분기문](./02_분기문.md) | `break`, `continue`, 흐름 탈출과 건너뛰기 |

## 수업 포인트

반복문은 “초기식, 조건식, 증감식, 본문”의 실행 순서를 손으로 적어 보면 이해가 빠릅니다. 분기문은 반복문 내부에서 사용될 때 흐름이 크게 달라지므로, 작은 예제부터 추적하는 방식으로 진행하면 좋습니다.

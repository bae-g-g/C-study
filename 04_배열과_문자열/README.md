## 수업 포인트

배열은 포인터 단원으로 넘어가는 다리입니다. 각 원소의 주소가 어떻게 증가하는지, `arr[i]`가 실제로 어떤 위치를 가리키는지 계속 확인하면서 보는 것이 좋습니다.

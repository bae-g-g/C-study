# 05. 함수

반복되는 코드를 이름이 있는 단위로 나누고, 값을 주고받는 방법을 다루는 단원입니다.

함수의 선언, 호출, 매개변수, 반환값을 정리하면 이후 포인터와 함수 인자 전달을 훨씬 쉽게 이해할 수 있습니다.

## 수업 포인트

함수는 “입력, 처리, 출력”의 작은 프로그램입니다. 매개변수와 반환값을 표로 적어 보면 함수의 역할이 선명해지고, 포인터 단원에서 주소를 넘기는 이유도 자연스럽게 이어집니다.

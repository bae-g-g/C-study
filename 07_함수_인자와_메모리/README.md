# 07. 함수 인자와 메모리

## 이미지 매칭 메모

`CBV`는 값 전달, `CBA`는 주소 전달, `mcr`은 컴파일/런타임 구분, `mms`는 메모리 구조 설명에 우선 연결합니다.

## 수업 포인트

함수 포인터는 문법이 낯설지만, 결국 “실행할 함수의 주소를 변수에 담는다”는 개념입니다. 콜백과 핸들 단원에서는 함수 포인터가 실제 설계 도구로 쓰이는 이유를 함께 확인합니다.

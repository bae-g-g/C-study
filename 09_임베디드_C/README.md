# 09. 임베디드 C

하드웨어와 가까운 C 코드에서 자주 만나는 비트 조작, 구조체/공용체, 문자열 연산을 다루는 단원입니다.

앞 단원에서 배운 메모리, 포인터, 배열 개념을 실제 시스템 프로그래밍 감각으로 연결합니다.

## 수업 포인트

임베디드 C는 값을 “몇 비트로, 어느 위치에, 어떤 구조로” 저장하는지 계속 의식해야 합니다. 비트 연산은 작은 예제를 손으로 계산해 보고, 구조체는 실제 메모리 배치를 그려 보면서 진행하면 좋습니다.

# C Study Main

## 진행 

1. 각 단원 폴더의 `README.md`에서 학습 순서를 먼저 확인합니다.
2. 번호가 붙은 문서를 순서대로 읽고, 예제 코드는 직접 컴파일해 봅니다.
3. 그림이 있는 문서는 그림을 먼저 보고 코드가 어떤 메모리 상태를 만드는지 따라갑니다.
4. 포인터 이후 단원은 이전 단원의 배열, 함수, 메모리 모델을 계속 되짚으면서 봅니다.
